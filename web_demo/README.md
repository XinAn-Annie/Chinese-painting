# Web Demo

`index.html` 是前端入口。完整功能请返回项目根目录，双击 `启动画基因.bat`，然后使用：

```text
http://127.0.0.1:8000/web_demo/index.html
```

网页使用本地 Plotly、字体、图片和 SVG，不依赖 CDN。颜色与印章启发式分析在浏览器内执行；题跋检测、OCR 和 Qwen 通过同一个本地 8000 服务访问。图片不会发送到外部推理 API。

## 路由

- `/services/inscription-detector/`：题跋区域检测。
- `/services/ocr/`：PaddleOCR 题跋识别。
- `/services/zhihua/`：本地 Qwen 赏析和追问。

## 交互边界

- 新图片会触发新的 OCR、颜色、印章和技法分析。
- 同一幅画的后续追问只更新右侧赏析文本，复用已有分析 ID，不重新识图或改写技法图表。
- 颜色结果只在问题涉及颜色、设色、色彩、墨色等内容时传递给 Qwen。
- 印章矩阵分数是未校准的规则证据分，不是识别概率。
- 五类技法分数是模型相对倾向，不是学术鉴定。

开发者可在已完成首次安装后使用根 `.venv` 单独调试各服务；普通用户不需要单独运行子服务。
