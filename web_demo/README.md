# Web Demo

入口文件是 `index.html`。完整功能请返回项目根目录，双击 `启动画基因_Google.bat` 或 `启动画基因_Edge.bat`；首次运行会自动安装依赖、下载 Qwen 模型并启动题跋检测器、PaddleOCR、知画与本地网页。

页面引用了 Plotly、Three.js 和 Google Fonts 的 CDN 资源，因此 3D 可视化和字体加载需要联网。

仅使用颜色分析和印章热力图时，可以直接双击 `index.html`。题跋文字识别需要保持一键启动窗口开启；图片不会发送到外部识别 API。

启动器会管理全部本地服务，普通用户不需要执行下面的开发命令。若要单独调试 PaddleOCR，可在已经运行过一次启动器后执行：

```bash
& '.\.venv\Scripts\python.exe' .\mcp_services\ocr\server.py
```

服务监听 `http://127.0.0.1:8004`。网页只把检测器裁剪出的题跋区域发送到该服务。服务不可用时页面会提示错误，不会改用整张画识字。

单独调试题跋区域检测器：

```powershell
& '.\.venv\Scripts\python.exe' .\mcp_services\inscription_detector\server.py
```

检测器监听 `http://127.0.0.1:8005`。点击“识别题跋文字”后，网页先向 8005 请求题跋框，再将每个裁剪区域发给 8004 的 PaddleOCR，并把文字框坐标还原到原图。无可信题跋框时直接显示“未检测到”，不生成词云。

## 知画国画赏析

网页通过本机 `8006` 服务调用启动器自动下载的 `Qwen2.5-VL-3B-Instruct`，默认不连接知识库，只依据上传画面回答；回答完成后，服务仅在可见证据满足受控规则时附加专业术语，不会把词表中的物象写回画面。浏览器中无需保存推理地址或密钥。

必须先点击页面上方的“分析颜色”，完成本幅画的传统色匹配后，才能点击“请知画赏析”。网页会把已经识别出的传统色名发送给本地服务；赏析只能使用这些名称，并统一显示为“推测为XX色”。普通颜色名和未被本幅画颜色分析识别出的传统色会被后端过滤。

显存不足时服务会自动把部分模型权重放入系统内存；只有 CPU 的电脑也可以启动，但生成速度可能很慢。首次请求需要加载模型，后续请求会更快。完整环境变量和远程兼容模式见 `mcp_services/zhihua/README.md`。


印章模块使用 `seal-detector.js`，按红色、方形或椭圆边界、内部文字状镂空三级筛选。红色越鲜艳，颜色证据分越高；外形和镂空决定候选所处阶段，鲜艳的纯红色块仍不会被当成高分印章。原图只标注第二、第三阶段候选：第二阶段为蓝色虚线框，第三阶段为蓝色实线框。页面另提供 24×16 科研矩阵，可导出 PNG 或 JSON。该分数未经标注数据校准，不是统计概率；文字状镂空只检查封闭孔洞、曲折度和分布，不识读印文。朱文印、断边、旋转和很小的印章可能漏检。
